# Contributing

Thank you for contributing to Database Fundamentals.

This repository belongs to the Knowledge layer of the ecosystem and focuses on database theory, SQL learning, data modeling, and practical exercises.

---

# Contribution Principles

Contributions should focus on:

* Database theory
* SQL learning resources
* ERD diagrams
* Data modeling concepts
* Practice exercises
* Query optimization examples
* Educational documentation

Contributions should not focus on:

* Production database infrastructure
* Database deployment automation
* Production migration systems
* Framework-specific integrations

Those belong to other repositories in the ecosystem.

---

# Repository Structure

```text
theory/
diagrams/
exercises/
examples/
```

Please place contributions in the appropriate directory.

---

# Writing Guidelines

* Use clear and concise English.
* Focus on conceptual understanding.
* Include practical SQL examples when appropriate.
* Keep examples small and educational.
* Follow Markdown best practices.

---

# Commit Convention

Examples:

feat: add normalization guide

docs: improve indexing explanation

fix: correct erd diagram

refactor: reorganize sql exercises

---

# Pull Request Checklist

Before submitting:

* Technical information is accurate.
* SQL examples are valid.
* Diagrams are correct.
* Markdown formatting is consistent.
* Content aligns with the Knowledge layer philosophy.
