# SQL Queries Examples

This directory contains progressively more advanced SQL query examples.

## Learning Order

1. SELECT
2. WHERE
3. ORDER BY
4. GROUP BY
5. HAVING
6. INNER JOIN
7. LEFT JOIN
8. Subqueries
9. Common Table Expressions (CTEs)

## Learning Outcome

After completing these examples, you should be able to:

- Retrieve data efficiently
- Filter records
- Sort results
- Aggregate information
- Combine related tables
- Write nested queries
- Use Common Table Expressions (CTEs)

These skills provide the foundation for building complex SQL reports and data analysis queries.
