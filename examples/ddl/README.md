# Data Definition Language (DDL)

This section contains examples of SQL Data Definition Language (DDL) commands.

DDL is used to define and modify database structures such as databases, tables, columns, and constraints.

## Learning Objectives

After completing these examples, you should be able to:

- Create databases
- Create tables
- Select appropriate data types
- Define primary keys
- Apply common constraints
- Design simple schemas
