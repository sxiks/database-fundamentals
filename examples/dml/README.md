# Data Manipulation Language (DML)

This section contains examples of the most common SQL commands used to manipulate data.

## Learning Objectives

After completing these examples, you should be able to:

- Insert records
- Update existing records
- Delete records
- Understand how data changes affect tables

| 02-update.sql | UPDATE statement |
| 03-delete.sql | DELETE statement |
