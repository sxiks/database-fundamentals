# Changelog

All notable changes to this repository will be documented in this file.

The format is based on Keep a Changelog and this project follows Semantic Versioning principles where applicable.

---

## [1.0.0] - 2026-06

### Added

* Repository restructured as a Knowledge repository.
* Added `theory/` directory for database concepts.
* Added `diagrams/` directory for ERDs and database visualizations.
* Added `exercises/` directory organized by difficulty level.
* Added `examples/` directory with SQL learning examples.
* Added learning roadmap and study recommendations.

### Changed

* Renamed repository from `template-database` to `database-fundamentals`.
* Replaced template-oriented documentation with educational content.
* Updated repository structure according to the ecosystem taxonomy.

### Removed

* Removed template-specific configuration directories.
* Removed schema management template structure.
* Removed migration template responsibilities.
* Removed seed management template responsibilities.
