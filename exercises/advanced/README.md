# Advanced Exercises

## Goal

Apply database fundamentals to scenarios that resemble real-world systems.

## Structure

### indexing

Topics:

- Index creation
- Query optimization
- Performance comparison

Learning Outcome:

- Understand how indexes affect query execution.

---

### transactions

Topics:

- ACID Properties
- Transaction Control
- Isolation Levels

Learning Outcome:

- Maintain data consistency in concurrent environments.

---

### query-optimization

Topics:

- Execution plans
- Query improvements
- Performance analysis

Learning Outcome:

- Identify inefficient queries and improve them.

---

### assessments

Topics:

- End-to-end database design
- Schema creation
- Data analysis

Learning Outcome:

- Integrate all concepts learned throughout the repository.

## Completion Criteria

Students should be able to:

- Design complete database solutions
- Optimize database performance
- Build production-like schemas
- Solve realistic database challenges
