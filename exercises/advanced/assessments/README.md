# Assessments

## Goal

Complete practical projects that combine all concepts covered in this repository.

## Requirements

Each assessment should include:

- Data modeling
- SQL schema creation
- Relationships
- Normalization
- Indexing decisions
- Complex queries

## Suggested Projects

### Library Management System

Design a database for:

- Books
- Authors
- Members
- Loans

Deliverables:

- ERD
- SQL schema
- Sample data
- Business queries

---

### E-Commerce Database

Design a database for:

- Products
- Categories
- Customers
- Orders
- Payments

Deliverables:

- ERD
- SQL schema
- Indexing strategy
- Reporting queries

---

### Hospital Management System

Design a database for:

- Patients
- Doctors
- Appointments
- Treatments

Deliverables:

- ERD
- SQL schema
- Normalization analysis
- Operational queries

## Final Outcome

Students should be able to design complete relational databases from business requirements.
