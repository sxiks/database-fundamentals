# Intermediate Exercises

## Goal

Combine multiple database concepts to solve realistic relational database problems.

## Structure

### relationships

Topics:

- One-to-One
- One-to-Many
- Many-to-Many

Learning Outcome:

- Implement relationships using foreign keys.

---

### er-modeling

Topics:

- Entity-Relationship Modeling
- ERD Design
- Schema Translation

Learning Outcome:

- Transform business requirements into database schemas.

---

### normalization

Topics:

- 1NF
- 2NF
- 3NF

Learning Outcome:

- Remove redundancy and improve schema quality.

---

### joins

Topics:

- INNER JOIN
- LEFT JOIN
- RIGHT JOIN

Learning Outcome:

- Query data across multiple related tables.

---

### aggregations

Topics:

- GROUP BY
- HAVING
- Aggregate Functions

Learning Outcome:

- Generate summarized business reports.

## Completion Criteria

Students should be able to:

- Design normalized schemas
- Create relationships correctly
- Query multiple tables using joins
- Produce aggregated reports
