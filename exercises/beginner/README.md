# Beginner Exercises

## Goal

Practice the foundational SQL concepts required to create and query relational databases.

## Structure

### sql-fundamentals

#### tables

Topics:

- CREATE TABLE
- Data types
- PRIMARY KEY
- NOT NULL
- UNIQUE

Learning Outcome:

- Create well-defined relational tables.

---

#### insert-data

Topics:

- INSERT INTO
- Multiple inserts
- Sample datasets

Learning Outcome:

- Populate tables with valid data.

---

#### basic-queries

Topics:

- SELECT
- WHERE
- ORDER BY
- LIMIT

Learning Outcome:

- Retrieve and filter data efficiently.

---

#### aggregate-functions

Topics:

- COUNT
- AVG
- SUM
- MIN
- MAX

Learning Outcome:

- Generate simple reports using aggregate functions.

## Completion Criteria

Students should be able to:

- Create tables
- Insert data
- Execute basic queries
- Use aggregate functions
